# Playbook: newsletter or article draft from supplied sources

Use when the owner asks for a draft built from transcripts, notes, earlier articles, or questions the community has asked.

## Input

- Topic and audience, language, approximate length.
- Supplied sources: transcripts, notes, links the owner has pasted as text.
- House style notes in USER.md, if any.

## Output

1. Three title options.
2. The draft: a hook paragraph, three to five sections, and a short close with one takeaway.
3. A source list mapping each section to the transcript passage, timestamp, or note it uses.
4. "Check before publishing": every name, number, quote, and claim you could not trace to a supplied source.

Quotes must be verbatim from the supplied text and short. Paraphrase everything else. If a byline mentions you, describe yourself as an AI collaborator.

## Quality bar

The owner can publish after one editing pass. Nothing in the draft depends on a source the owner has not seen.

## Never

- Publish, schedule, or post. Return the draft here; the owner publishes.
- Copy long passages from copyrighted sources or attribute invented quotes to real people.
- Use private memory about third parties in public text without the owner's explicit say-so.
